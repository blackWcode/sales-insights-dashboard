# 📊 Sales Insights Dashboard – From Chaos to Clarity

This project showcases a dynamic sales dashboard built using Excel and Power BI. It transforms raw monthly sales data into visual insights, helping stakeholders make informed decisions quickly and confidently.

---

## 🔧 Tools & Technologies

- Power BI  
- Excel  
- Power Query  
- DAX  
- Data Visualization Best Practices

---

## 📁 Dataset

A sample dataset was generated with:
- 12 months of data  
- 4 products, 4 regions, and 4 customer segments  
- Revenue, cost, and profit metrics  

📂 File: [`sales_data.xlsx`](./sales_data.xlsx)

---

## 📈 Key Metrics & Features

- Monthly revenue and profit trends  
- Regional and product breakdowns  
- Customer segment performance  
- Interactive slicers for deep-dive analysis  
- Highlights of high- and low-performing segments

---

## 💡 Business Value

> "The dashboard reduces manual reporting time by over 60%, uncovers product and regional trends, and supports proactive decision-making for sales and marketing teams."
